## ✨ 主な特徴

- **🎨 洗練された Studio Aurora UI**
  - 音量に反応するオーロラグラデーション背景・リアルタイム VU メーター・イコライザーアニメーションを搭載。
  - 待機時はフレームレートを自動最適化し、ゲーム中でも軽快に動作します。
- **🎧 ゼロエコー・デュアル出力エンジン**
  - マイク音声＋効果音をリアルタイム合成して **VC（通話相手）** へ送信しつつ、**自分のヘッドホン** には効果音だけをモニター再生。自分の声が遅れて跳ね返るエコーを防ぎます。
- **📂 ドラッグ＆ドロップで即登録（動画ファイルも対応）**
  - `MP3 / WAV / OGG / M4A / FLAC / AAC / OPUS` はもちろん、**`MP4 / MOV / MKV / WebM`** などの動画ファイルもドロップするだけで音声を自動抽出して登録できます。
- **⌨️ グローバルホットキー対応**
  - ゲーム中や Discord の裏画面からでも、割り当てたキー（英数字・ファンクションキー・テンキー等）で瞬時にポン出し可能。
- **🎚️ 細かな音量コントロール＆検索**
  - 「VC送信」「モニター」「マイク」の 3 系統マスターフェーダーに加え、**サウンドごとの個別音量スライダー**、**インクリメンタル検索**、**ループ再生**、**名前変更**に対応。
- **🛡️ 安全なデバイス切替＆接続ステータス表示**
  - ヘッダーの `● VC` / `● MON` / `● MIC` バッジで接続状態を常時確認可能。使用できないデバイスを選んでもアプリが終了せず、警告通知とともに安全に動作を継続します。

## 📦 動作環境

- **OS**: Windows 10 / 11 (64-bit)
- **必須ドライバ**: [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)（無料）
- **Python 等のインストール**: **不要**（`DiscordSoundboard.exe` 単体で動作します）

---

## 🚀 セットアップ手順（初回のみ・約 1 分）

### 1. VB-Audio Virtual Cable のインストール
1. [VB-Audio Virtual Cable 公式サイト](https://vb-audio.com/Cable/) から無料版をダウンロードし、ZIP を解凍します。
2. `VBCABLE_Setup_x64.exe` を **右クリック →「管理者として実行」** してインストールします。
3. インストール完了後、PC を再起動します。

### 2. Discord の音声設定
1. Discord を開き、左下の **⚙️ ユーザー設定** → **音声・ビデオ** を開きます。
2. 以下のように設定します：

| 設定項目 | 指定するデバイス |
| :--- | :--- |
| **入力デバイス** | **`CABLE Output (VB-Audio Virtual Cable)`** |
| **出力デバイス** | 普段お使いのヘッドホン／スピーカー（変更不要） |

> 💡 アプリ側で「マイクパススルー」が ON になっていれば、あなたの声とサウンドボードの音の両方が通話相手に届きます。

### 3. アプリの起動
1. `DiscordSoundboard.exe` をダブルクリックして起動します。
2. 音声・動画ファイルをウィンドウへドラッグ＆ドロップ（または **`＋ 音声を追加`**）して登録します。
3. カードをクリック、または設定したホットキーを押すと即時再生されます！

## 🎛️ 画面と操作ガイド

| コントロール | 説明 |
| :--- | :--- |
| **カードクリック / `▶`** | サウンドの再生／停止を切り替え |
| **`⏹ ALL STOP`** | 再生中のサウンドをすべて即座に停止 |
| **マイクパススルー** | ON でマイク音声と効果音を合成して VC へ送信 |
| **VC送信 (相手へ)** | 通話相手に届く効果音の音量（0%〜150%） |
| **モニター (自分へ)** | 自分のヘッドホンに聞こえる効果音の音量（0%〜150%） |
| **マイク音量** | VC へ送る自分の声の音量（0%〜150%） |
| **カード内 `🔊` スライダー** | 各サウンド個別の音量バランス調整（0%〜150%） |
| **`KEY 未設定` / `◆ X`** | グローバルホットキーの割り当て（`Esc` で解除） |
| **`🔁`（ループ）** | 停止するまで繰り返し再生（BGM などに便利） |
| **`✏`（名前変更）** | サウンドの表示名を変更 |
| **`⚙ デバイス設定` / `↻ 更新`** | マイク・VC送信先・モニターの変更および再スキャン |
| **`🔍 検索バー`** | サウンド名・ホットキーで瞬時に絞り込み |

## 🛠️ トラブルシューティング

<details>
<summary><b>Windows Defender SmartScreen の警告が出る場合</b></summary>

個人制作の未署名 `.exe` のため、初回起動時に「Windows によって PC が保護されました」と表示される場合があります。  
**「詳細情報」→「実行」** をクリックして起動してください。

</details>

<details>
<summary><b>通話相手に音が届かない / <code>▲ VC</code> が赤表示になる場合</b></summary>

1. アプリ上部の **`⚙ デバイス設定`** を開きます。
2. **📡 VC送信先** が **`CABLE In ... (VB-Audio Virtual Cable)`** になっているか確認してください（`WASAPI` または `DS` を推奨）。
3. Discord の **入力デバイス** が **`CABLE Output (VB-Audio Virtual Cable)`** になっているか確認してください。
4. デバイスを抜き差しした場合は **`↻ 更新`** ボタンを押すと再接続されます。

</details>

<details>
<summary><b>ゲーム中にホットキーが反応しない場合</b></summary>

管理者権限で起動しているゲームの裏では Windows の仕様上キー入力がフックできない場合があります。その場合は `DiscordSoundboard.exe` も **右クリック →「管理者として実行」** で起動してください。

</details>

├── README.md               # 本ドキュメント
└── samples/                # 動作確認用サンプル効果音
